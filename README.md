# Shuttle Fantasy results feed

Published every hour by the Shuttle Fantasy app's data job. Not edited by hand; each publish replaces the previous one.

- `manifest.json`: what's here and when the results were imported (the app checks this first).
- `results.json`: fantasy points for every entry in the app's player pool, per Tournament Week, scored from real match results.

Results come from English Wikipedia tournament pages (CC BY-SA 4.0), which cite BWF tournament software. This feed is shared under the same licence.
